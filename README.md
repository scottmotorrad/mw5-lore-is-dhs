# IS DHS Mod — Variant Roster

Adds internal double heat sinks to IS mechs that have them in the lore per Sarna for canon mechs or MWO for hero mechs. Please let me know if I missed any or included any that shouldn't be!

Base cooling is scaled by engine size: `(engine rating ÷ 25, rounded down) × 0.2`. A 250+ engine mounts the full 10 internal sinks (2.0); smaller engines mount fewer.
